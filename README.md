# My Favorite Series: Stranger Things

## Overview
**Stranger Things** is a *science fiction horror drama* created by the Duffer Brothers. It is set in the 1980s in the fictional town of Hawkins, Indiana.

## Main Characters
* **Eleven** – A young girl with psychokinetic abilities.
* **Mike Wheeler** – The loyal leader of the friend group.
* **Jim Hopper** – The chief of police in Hawkins.

## Why I Recommend It
1. Great 1980s nostalgia and soundtrack.
2. Strong character development across every season.
3. Thrilling mystery and suspense.

> "Friends don't lie." — Eleven

For more details, check out the [Official Netflix Page](https://netflix.com).
